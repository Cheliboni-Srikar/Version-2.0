# Optional room adviser
From the source root: python3 examples/study_space_adviser.py
Run the checks: python3 -m unittest discover -s tests -v
Use Python 3.10 or later. No extra packages, account or data files are needed. For Windows, use py -3 if appropriate. Predict the full and missing-status outputs in §2.6 before running. Compare observed-output.txt with the results. Without Python, use the paper trace and captured output. The demo does not book rooms or verify physical status.
