# Module outline and status

Both chapters have substantive drafts. Teammate review of this revision is pending. A module outline and the guide are separate: the outline maps the learning sequence; the guide teaches it.
| Chapter | Sections in learning order | Prior knowledge | Outcome and practice |
|---|---|---|---|
| 1 Software | 1.1 hardware and software; 1.2 input/process/output; 1.3 algorithm/program; 1.4 requirements/validation; 1.5 testing/updates | Everyday computer use | Classify a component; trace a program branch; predict outputs for normal and changed inputs. Activities A–B and chapter check. |
| 2 Symbolic AI | 2.1 representation; 2.2 logic; 2.3 rule reasoning; 2.4 search; 2.5 planning; 2.6 expert system; 2.7 explanations/limits | Chapter 1; AND and IF–THEN introduced before use | Derive a conclusion, identify missing support, reconstruct a path, check a plan, and explain an expert-system trace. Activities C–F and chapter check. |

Study depth: one small positive rule system, one graph and one plan. Advanced proof algorithms, neural-network training and industrial deployment are outside this introductory revision. This is a project study aid; no official final-exam blueprint was supplied.
